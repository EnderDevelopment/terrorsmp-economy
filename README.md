# Terrorsmp.com Minecraft Plugin

This Minecraft plugin for Paper 1.21.11 replicates the economy system from donutsmp.net, including commands like /pay, /ah, /order, and /bal. It features a custom scoreboard displaying Terrorsmp.com, money, playtime, and kills. The plugin is designed to provide a unique economy experience with a distinct visual identity.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Paper 1.21.11 server.
3. Restart or reload your server to enable the plugin.

## Use

1. Use the `/pay <player> <amount>` command to send money to another player.
2. Use the `/ah` command to open the auction house.
3. Use the `/order <item> <amount> <price>` command to create an order.
4. Use the `/bal` command to check your balance.
